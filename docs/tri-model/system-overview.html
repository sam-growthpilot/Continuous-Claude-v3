Claude orchestrates · Grok builds · Codex grades & fixes · Disk is the bus

Three training families. Fixed roles. No self-grading.

Disk is the bus

Claude, Codex, and Grok do not share process memory or CCv3 hooks. The workroom is the shared language: CONTRACT.md is source of truth; status.json advances only via the hub; inboxes carry typed tasks.

Room layout

.workroom/rooms/<room-id>/
├── CONTRACT.md     # SoT blueprint
├── status.json     # phase · next_actor
├── ROOM.yaml       # roster · scopes
├── THREAD.md       # append-only log
├── intake/          # grill-me answers
├── research/        # Grok dumps
├── milestones/      # M1-scope · M1-result
├── findings/        # [Codex]/[Grok] booth
├── patches/         # *.diff review-gate
└── inbox/
    ├── claude/  codex/
    ├── grok/    human/

Cold start rule Any model (or new Claude session) reconstructs work from CONTRACT.md + status.json + own inbox — never from a Grok/Claude session plan path alone.
Not the bus ~/.grok/sessions/…/plan.md, chat transcripts, or agent cache/latest-output.md alone. Those are ephemeral; copy durable state into the room.

Harness safety (probe-backed)

Grok CLI 0.2.93+

Read-only = tools only

  • --sandbox is decorative headless
  • --tools "read_file,list_dir,grep" blocks writes
  • -w ignored in -p → hand-rolled worktrees
  • Can run shell in implement — verify harder
Codex CLI 0.144.1+

Sandbox is real

  • --sandbox read-only | workspace-write
  • --disable multi_agent default (no Ultra thrash)
  • Windows: no subprocess in workspace-write
  • Allowlist: gpt-5.6-sol/terra/luna · 5.5 · 5.4…
